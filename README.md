
# 🔐 Neon Login Page

A modern and visually appealing login page built using **HTML5** and **CSS3**. This project showcases a futuristic neon-inspired interface with animated glowing borders, a dark-themed design, and responsive layout techniques.

The purpose of this project was to strengthen my understanding of HTML structure and advanced CSS styling while recreating a modern user interface without using JavaScript or external CSS frameworks.

---

## ✨ Features

- 🎨 Modern dark-themed user interface
- 💡 Animated neon border created using CSS
- 🌈 Cyan and magenta glow effects
- 👤 Username input field
- 🔒 Password input field
- 👁️ Password visibility icon (UI only)
- 🔘 Stylish login button with hover animation
- 🔗 Forgot Password and Sign Up links (UI only)
- 📱 Responsive centered layout
- ✨ Smooth hover effects and transitions

---

## 📖 Project Overview

### HTML

The HTML file defines the structure of the login page.

It includes:

- Login card container
- Page heading
- Login form
- Username field
- Password field
- Submit button
- Forgot Password link
- Sign Up link

The HTML is kept clean and easy to understand, making it suitable for beginners learning web development.

---

### CSS

The CSS file is responsible for the visual appearance of the project.

Some of the styling techniques used include:

- Flexbox for centering content
- CSS pseudo-elements (`::before` and `::after`)
- `conic-gradient()` for the animated neon border
- CSS animations using `@keyframes`
- Hover effects
- Rounded corners
- Drop shadows
- Smooth transitions
- Dark theme colour palette

The rotating neon border is created entirely with CSS, demonstrating how animations can enhance a user interface without JavaScript.
